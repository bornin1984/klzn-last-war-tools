For N hunts, hunting + own rally = (N × hunt reward + discovery reward + boss reward) ÷ (N × hunt stamina + rally stamina − discovery credit) × 10. Hunting + others rally = (N × hunt reward + discovery reward) ÷ (N × hunt stamina − discovery credit) × 10. Rally only = boss reward ÷ rally stamina × 10. The discovery credit is a model assumption: set it to zero if no actual stamina is refunded.
